# 出院叙述与照护交接中的指令冲突核对

本项目整理社区照护协调员会把医院出院记录、患者家属补充和后续门诊安排整理给接班人员。不同记录常用简称指同一项护理动作，且修订版可能只改了某个对象的频次；若把整段摘要当成当前指令，旧频次会重新进入交接单，家属也无法知道哪项内容仍待医护确认。

演练资料位于 `data/care.json`，内容为合成记录，保留不同来源的原始表述和修订关系。项目环境使用 Python 3.11 标准库。

当前资料检查入口为 `python3 -m unittest discover -s tests -v`。检查仅确认 JSON 文件可以读取、记录字段完整且每条原文存在，不会生成业务判断。尚无面向使用者的业务命令。
